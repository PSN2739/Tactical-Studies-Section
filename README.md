# Tactical-Studies-Section

## ประกาศ-ประชาสัมพันธ์

- ครูที่ได้รับอนุมัติแล้วสามารถเข้าสู่ระบบด้วยบัญชีครูเดิมเพื่อสร้างประกาศได้ ผู้ชมทั่วไปอ่านประกาศที่กำลังเผยแพร่ได้
- ข้อมูลประกาศจัดเก็บในแท็บ `Announcements` ที่ Apps Script สร้างใน Google Sheet เดิม โดยไม่เปิดสิทธิ์ชีตให้สาธารณะ
- ตั้งวันและเวลาเริ่ม/สิ้นสุดได้ตามเวลาไทย เนื้อหาเป็นข้อความธรรมดา พร้อมปุ่มแทรกอิโมจิ
- ประกาศเรียงตามวันเริ่มล่าสุด คลิกชื่อเพื่ออ่านเนื้อหา และแสดงป้าย `NEW` ในช่วง 7 วันแรก
- ประกาศที่หมดอายุจะไม่แสดง และถูกลบจากชีตเมื่อระบบตรวจพบ รวมถึงงานตามเวลาใน Apps Script ที่ตรวจทุกชั่วโมง
- การสร้างงานตามเวลาครั้งแรกอาจต้องให้เจ้าของ Apps Script อนุญาตสิทธิ์เพิ่มเติมก่อนใช้งาน
