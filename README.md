# Tactical-Studies-Section

## ประกาศ-ประชาสัมพันธ์

- ครูที่ได้รับอนุมัติแล้วสามารถเข้าสู่ระบบด้วยบัญชีครูเดิมเพื่อสร้างประกาศได้ ผู้ชมทั่วไปอ่านประกาศที่กำลังเผยแพร่ได้
- ข้อมูลประกาศจัดเก็บในแท็บ `Announcements` ที่ Apps Script สร้างใน Google Sheet เดิม โดยไม่เปิดสิทธิ์ชีตให้สาธารณะ
- ตั้งวันและเวลาเริ่ม/สิ้นสุดได้ตามเวลาไทย เนื้อหาเป็นข้อความธรรมดา พร้อมปุ่มแทรกอิโมจิ
- ประกาศเรียงตามวันเริ่มล่าสุด คลิกชื่อเพื่ออ่านเนื้อหา และแสดงป้าย `NEW` ในช่วง 7 วันแรก
- ประกาศที่หมดอายุจะไม่แสดง และถูกลบจากชีตเมื่อระบบตรวจพบ รวมถึงงานตามเวลาใน Apps Script ที่ตรวจทุกชั่วโมง
- หาก Apps Script ขอสิทธิ์เพิ่ม ให้เจ้าของเปิดโปรเจกต์ใน Apps Script เลือก `setupAnnouncementCleanup` แล้วกด Run และอนุญาตสิทธิ์ งานลบข้อมูลจะทำงานทุกชั่วโมง

## พื้นที่เข้าสอบตามพิกัด

- การกำหนดพื้นที่เป็นทางเลือก หากไม่เลือก ระบบไม่แสดงแผนที่และไม่ขอตำแหน่ง GPS
- ครูสามารถเปิดการจำกัดพื้นที่ในหน้าสร้างข้อสอบ แล้วคลิกแผนที่เพื่อปักหมุดสนามสอบ หรือใช้ตำแหน่ง GPS ของอุปกรณ์
- กำหนดรัศมีเป็นเมตรได้ตั้งแต่ 10 ถึง 50,000 เมตร ระบบบันทึกจุดสอบและรัศมีแยกตามข้อสอบ
- เมื่อเปิดข้อสอบที่จำกัดพื้นที่ ผู้เข้าสอบต้องอนุญาตตำแหน่ง GPS และอยู่ภายในรัศมีที่กำหนดก่อนระบบออกสิทธิ์เริ่มสอบ
- แผนที่ Leaflet และภาพแผนที่ OpenStreetMap จะโหลดเมื่อครูเปิดตัวเลือกจำกัดพิกัดเท่านั้น ต้องเชื่อมต่ออินเทอร์เน็ต
- การตรวจตำแหน่งทำครั้งเดียวตอนเริ่มสอบเพื่อจำกัดการติดตามตำแหน่ง ข้อมูลพิกัดผู้เข้าสอบไม่ถูกบันทึก แต่การตรวจจากเบราว์เซอร์/GPS ไม่สามารถป้องกันอุปกรณ์ที่ปลอมตำแหน่งได้

## เกณฑ์ผ่านและจำนวนครั้งสอบ

- เกณฑ์ผ่านเป็นทางเลือก หากเลือก “ไม่กำหนด” ระบบจะแสดงเฉพาะคะแนนที่ได้ โดยไม่ระบุผ่านหรือไม่ผ่าน
- หากเลือกเกณฑ์ผ่าน สามารถกำหนดเป็นเปอร์เซ็นต์หรือจำนวนข้อได้
- จำนวนครั้งสอบไม่บังคับกรอก หากเว้นว่างระบบกำหนดให้สอบได้ 1 ครั้ง และกำหนดได้ตั้งแต่ 1 ถึง 999 ครั้งสำหรับช่วงสอบอื่น
- ข้อสอบหลังเรียนใช้เกณฑ์เปอร์เซ็นต์หรือจำนวนข้อที่ครูกำหนด: สอบซ้ำได้เมื่อไม่ผ่าน และสอบซ้ำไม่ได้เมื่อผ่าน โดยไม่จำกัดจำนวนครั้ง
- หากไม่กำหนดเกณฑ์ผ่านสำหรับข้อสอบหลังเรียน จะสอบได้ครั้งเดียวและแสดงคะแนนตามที่ทำได้โดยไม่ตัดสินผ่านหรือไม่ผ่าน

## ข้อมูลสรุปการเรียน

- Apps Script สร้างชีต `LearningSummary` จาก `Attendance`, `เจตคติ`, `QuizResults`, `ScooreT` และผลจากชีต `Assessment_*` โดยใช้เลขประจำตัวและเลขที่เป็นคีย์เชื่อม
- หน้า “ข้อมูลการเรียน” ตรวจสอบอีเมลจากคอลัมน์ Q และรหัสผ่านจากคอลัมน์ A ของ `LearningSummary` แล้วอ่านโปรไฟล์ คะแนนเจตคติ H คะแนนก่อนเรียน I คะแนนหลังเรียน J ประเมินความรู้ K กิจเฉพาะ L คะแนนรวม O และคะแนนสุทธิ P จากแถวสรุปของผู้เรียน
- หากผู้เรียนมีรายการใน `Attendance` หลายแถว ระบบใช้ข้อมูลจากรายการที่มีวันที่ลงทะเบียนล่าสุด ทั้งการซิงก์ทันทีและการสร้างสรุปใหม่
- คอลัมน์ O (`total_score`) รวมค่าคะแนนใน H ถึง L, คอลัมน์ P (`total_score_ratio`) คำนวณ O ÷ 100 และคอลัมน์ Q (`email`) แสดงอีเมลของผู้เรียนจากคอลัมน์ F; ใช้ `ARRAYFORMULA` เพื่อคำนวณข้อมูลเดิมและแถวที่เพิ่มในอนาคตอัตโนมัติ
- หลัง deploy เวอร์ชันนี้ ให้ผู้ดูแลเรียก `rebuildLearningSummary` หนึ่งครั้งเพื่อสร้างค่า O/P/Q สำหรับข้อมูลเดิมทันที; หากยังไม่เรียกเอง ระบบจะ rebuild อัตโนมัติเมื่อมีคำขอที่ตรวจสอบ/ใช้งาน `LearningSummary` ครั้งถัดไป
- การลงทะเบียนเข้าเรียนและการบันทึกคะแนนผ่านระบบจะอัปเดตแถวสรุปทันทีหลังเขียนข้อมูลต้นทางสำเร็จ
- การบันทึกข้อมูลผ่านระบบจะอัปเดตสรุปทันที ส่วนการแก้ชีตต้นทางด้วยมือให้ผู้ดูแลเรียก `setupLearningSummarySync` ใน Apps Script หนึ่งครั้ง เพื่อติดตั้ง trigger ที่ซิงก์ข้อมูลหลังมีการแก้ไข
- หากต้องการสร้างสรุปครั้งแรกทันทีหรือซ่อมข้อมูล ให้ผู้ดูแลเลือกฟังก์ชัน `rebuildLearningSummary` ใน Apps Script แล้วกด Run ระบบจะเขียนสรุปชุดใหม่ก่อนล้างแถวเก่าที่เกิน และจะไม่ถือว่าสรุปพร้อมใช้งานหากการสร้างไม่สำเร็จ ชีต `LearningSummary` เป็นข้อมูลอนุพันธ์ ไม่ควรแก้โดยตรง
- การสร้างสรุปครั้งแรกอาจใช้เวลานานกว่าการเข้าสู่ระบบครั้งต่อ ๆ ไป เพราะระบบต้องอ่านชีตต้นทางเพื่อสร้างแถวสรุปทั้งหมด

## ผลสอบและการส่งคำตอบซ้ำ

- ผลใน `QuizResults` แยกตามผู้เรียนและแบบทดสอบ เพื่อไม่ให้การทำแบบทดสอบใหม่เขียนทับคะแนนของแบบทดสอบอื่น
- ระบบเก็บเฉลยของชุดคำถามไว้กับเซสชันฝั่งเซิร์ฟเวอร์ ทำให้การแก้ข้อสอบระหว่างที่ผู้เรียนกำลังสอบไม่เปลี่ยนคะแนนของเซสชันนั้น
- ระบบใช้ token ของการสอบเป็นรหัสอ้างอิงใน `QuizAttemptHistory` หากเบราว์เซอร์ส่งคำตอบเดิมซ้ำหลังการเชื่อมต่อขัดข้อง ระบบจะคืนผลเดิมและซ่อมข้อมูลสรุปที่ยังเขียนไม่ครบ แทนการนับเป็นการสอบครั้งใหม่
- การเพิ่มประวัติสอบจะอัปเดตแถวประวัติและมุมมองที่เกี่ยวข้อง โดยไม่เรียงและเขียนประวัติทั้งชีตใหม่ทุกครั้ง
